# Lexicove: специфікація v1

> **Lexicove** (lexicon + cove) — «затока слів», де кожна категорія слів є островом на карті. Ліцензія MIT. Документ складено 25.10.2026 за твоїми відповідями.

## 1. Суть

Безкоштовний open-source додаток для вивчення англійських слів і правил. Слова беруться з таблиць Notion (або додаються вручну чи з CSV), а навчання влаштоване як гра: валюта, магазин, ліги, дуелі, чат.

## 2. Жорсткі обмеження

- **0 грн на інфраструктуру.** Лише безкоштовні тарифи.
- **Без платного AI.** Озвучка й розпізнавання мовлення беруться з браузера чи системи або з безкоштовних відкритих моделей.
- **Публічний репозиторій на GitHub.** У коді немає жодних ключів і паролів. Код бачать усі, тому нагороди (XP, валюту) рахує сервер, а не браузер. Інакше будь-хто накрутить собі валюту через консоль.
- **Відкритий для всіх:** реєстрація, акаунти, модерація.

## 3. Платформи

| Де | Як |
|---|---|
| Будь-який браузер | Сайт |
| Телефон | Той самий сайт як PWA: «Додати на головний екран», іконка, повноекранний режим, робота без інтернету |
| Ноутбук (Windows / macOS / Linux) | Окрема програма на Tauri 2 у власному вікні: близько 10 МБ, автооновлення з GitHub Releases |

Для всіх трьох платформ один код React. Десктоп має кілька власних функцій (див. §11).

Без платного сертифіката підпису Windows під час встановлення покаже попередження «Невідомий видавець», і на macOS буде те саме. Для безкоштовних open-source програм це звична ситуація.

## 4. Технології (усе безкоштовне)

| Частина | Що | Навіщо |
|---|---|---|
| Інтерфейс | React + TypeScript + Vite | Один код для сайту, телефона й десктопу |
| Стилі й анімації | Tailwind CSS, Framer Motion, Lottie | Преміальні анімації, анімовані аватари |
| Десктоп | Tauri 2 | Приблизно в 10 разів легший за Electron |
| Бекенд | Supabase (Postgres, Auth, Realtime, Storage, Edge Functions) | Одна платформа для входу, бази, чату в реальному часі, файлів і серверної логіки |
| Офлайн | IndexedDB (Dexie) + Service Worker | Можна вчитися без інтернету, синхронізація відбудеться пізніше |
| Інтервальне повторення | FSRS (бібліотека `ts-fsrs`) | Сучасніший алгоритм, ніж SM-2 з Anki |
| Переклади інтерфейсу | i18next | Багатомовність |
| Графіки | Recharts | Статистика |
| Листи (підтвердження пошти) | Resend, безкоштовно 100 листів на день | Вбудована пошта Supabase має дуже жорсткі ліміти |
| Хостинг сайту | Vercel Hobby | Безкоштовно |
| Збірка десктопу | GitHub Actions → GitHub Releases | Безкоштовно для публічних репозиторіїв |

### Ліміти безкоштовного Supabase (звірити під час створення проєкту)

- 500 МБ бази, 1 ГБ файлів, 50 000 активних користувачів на місяць
- Близько 200 одночасних підключень у реальному часі (чат, дуелі)
- Після 7 днів без активності проєкт «засинає»

На старт вистачає із запасом. Якщо додаток виросте, саме тут першим знадобляться гроші або оптимізація.

## 5. Вхід і акаунти

- Google, email + пароль, GitHub, Discord, Notion (усе це вбудовано в Supabase Auth)
- **Гостьовий режим:** можна вчитися одразу, а пізніше прив'язати акаунт і зберегти прогрес. Чат, дуелі та ліги для гостей закриті.
- Видалення акаунта й експорт своїх даних

### Тестовий акаунт

- Роль `tester`: відкрито майже все (предмети, теми, рівні), багато валюти
- Прапорець `hidden_from_stats`: акаунт не потрапляє в ліги, рейтинги, загальну статистику й лічильники онлайну
- Створюється скриптом. Логін і пароль лежать у локальному `.env`, а не в репозиторії

## 6. Слова та Notion

### Джерела слів

1. **Notion** з двосторонньою синхронізацією
2. **Слова, додані прямо в додатку**
3. **Імпорт CSV / Excel** (і експорт)

### Підключення Notion

- Публічна інтеграція Notion через OAuth: користувач сам обирає, до яких сторінок дати доступ
- **Шаблон:** кнопка «Скопіювати шаблон» створює готові бази з твоєю структурою
- **Зіставлення колонок:** хто вже має свою таблицю, вказує, яка колонка містить слово, переклад, вимову, приклади, пояснення й категорію. Додаток запам'ятовує вибір
- Можна підключити кілька баз

### Структура шаблону (з твого Notion)

- **English words:** Word, Translation, Pronunciation, Examples, Explanation, Category (22 категорії), Added
- **English Rules:** Rule, Topic (Grammar / Vocabulary / Phrases / Pronunciation), Explanation, Examples, Added

### Синхронізація

- **Notion → додаток:** забираємо лише те, що змінилося з минулої синхронізації (за `last_edited_time`), на вимогу і у фоні
- **Додаток → Notion:** нове чи відредаговане слово записується в Notion через серверну функцію
- **Конфлікти:** перемагає пізніша зміна
- **Прогрес** навчання зберігається в Supabase, тож таблиця в Notion лишається чистою
- **Токен Notion** лежить лише на сервері в зашифрованому вигляді й ніколи не потрапляє в браузер
- Notion обмежує частоту запитів (у середньому 3 на секунду), тому слова кешуються, а запис іде пакетами

## 7. Режими навчання

### Основні

| Режим | Суть |
|---|---|
| Картки | Інтервальне повторення FSRS: складні слова повертаються частіше |
| Тест з варіантами | Вибрати переклад з 4 варіантів, в обидва боки (EN→UA, UA→EN) |
| Напиши слово | Перевірка правопису, підказка першими літерами |
| Пропущене слово | Речення з твоїх Examples, де слово замінене на ___ |
| Склади речення | Розставити перемішані слова прикладу в правильному порядку |
| Почуй і вибери | Слово озвучується, треба вибрати правильне |
| Диктант | Слово чи речення озвучується, треба записати |
| Вимова в мікрофон | Кажеш слово, додаток розпізнає й оцінює |
| Квіз з правил | Питання з бази English Rules |
| Сортування | Розкласти слова за категоріями з колонки Category |

### Ігри

- **Збери пари:** з'єднати слова з перекладами на час
- **Швидкісний раунд:** скільки слів устигнеш за 60 секунд
- **Словесний дощ:** слова падають згори, їх треба встигнути надрукувати
- **Шибениця**, **Wordle**, **кросворд**, **пошук слів**, **анаграми**, усе з твоїх слів
- **Правда чи ні:** бліц на швидкість

### Мовлення без прикрас

- Озвучка працює всюди. Голоси системні, тож якість залежить від пристрою.
- Розпізнавання мовлення в браузері є в Chrome, Edge і Safari, а у Firefox його немає. У десктопній програмі на Windows його, найімовірніше, теж немає (перевіримо). Запасний варіант: безкоштовна офлайн-модель Vosk (близько 40 МБ), яка завантажується лише під час першого вмикання режиму.
- Без платного AI вимова оцінюється за принципом «розпізнано правильне слово чи ні» з відсотком збігу, а не за окремими звуками.

## 8. Мотивація та економіка

- **XP** за кожну відповідь і **рівні** акаунта
- **Стрік** (вогник), **щоденна ціль**, заморожування стріку
- **Досягнення:** десятки значків («100 слів», «30 днів поспіль», «усі фразові дієслова», «10 перемог у дуелях»…)
- **Квести:** щоденні та щотижневі («пройди 3 аудіоуроки»)
- **Щоденна скринька** за вхід
- **Статистика:** календар активності в стилі GitHub, кількість нових / тих, що на повторенні / вивчених слів, точність за категоріями, найважчі слова, прогноз повторень, час навчання

### Валюта: Coins 🪙 (в українському інтерфейсі «монети»)

- Заробляються лише навчанням: уроки, квести, стріки, досягнення, ліги, дуелі. **За гроші не купуються.**
- Нарахування рахує сервер з денними лімітами, щоб не можна було накрутити

### Магазин

| Розділ | Приклади |
|---|---|
| Анімовані аватари | Персонажі, тварини, роботи з анімацією |
| Рамки аватара | Вогняна, неонова, золота, сезонні |
| Банери профілю | Анімовані фони |
| Теми оформлення | Див. нижче |
| Ефекти в чаті | Колір ніка, значок біля імені, стікери, емоції для дуелей |
| Титули | «Майстер фразових дієслів», «Нічна сова» |
| Сорочки карток | Дизайн зворотного боку флешкарток |
| Звукові пакети | Звуки правильної та неправильної відповіді |
| Бонуси | Заморожування стріку, x2 XP на 15 хвилин, підказки |
| Для улюбленця | Одяг і аксесуари (див. §10) |

- Інвентар, приміряння перед покупкою, подарунки друзям
- Рідкісні предмети лише за досягнення або сезон
- Анімації малюємо самі (SVG / Lottie) або беремо лише ті, чия ліцензія дозволяє публікацію в open-source

### Теми

- **Безкоштовні базові:** Темний преміум (за замовчуванням), Світла, Яскрава ігрова, Мінімал
- **У магазині:** Неон, Космос, Сакура, Ретро-термінал та інші
- Тема змінює кольори, фон, анімації та звуки

## 9. Соціальне

- **Профілі:** аватар, рамка, банер, титул, рівень, ліга, значки, статистика
- **Друзі:** заявки, список, статус онлайн
- **Особисті повідомлення**
- **Загальний чат і кімнати:** за рівнем (A1–C2), за темою (Phrasal verbs, IT English, Travel…), кімнати кланів
- Реакції, відповіді на повідомлення, згадки через @, стікери з магазину

### Дуелі

- 1 на 1 у реальному часі: 10 питань, перемагає швидший і точніший
- Рейтингові (ELO) і дружні, ставки монетами
- Питання генерує і відповіді перевіряє сервер
- Реванш одним кліком

### Ліги

- Щотижневі групи приблизно по 30 людей: Бронза → Срібло → Золото → Сапфір → Рубін → Діамант → Легенда
- Найкращі піднімаються, найгірші опускаються, нагорода монетами
- Окремий рейтинг серед друзів

## 10. «Здивуй мене»: мої ідеї

1. **Улюбленець:** тамагочі, що росте разом зі стріком. Його треба годувати й одягати, і він сумує, коли пропускаєш день
2. **Бос тижня:** особистий бос, складений з твоїх найважчих слів. Кожна правильна відповідь його б'є, а перемога дає рідкісний предмет
3. **Клани:** групи до 30 людей зі спільною тижневою ціллю, клановою скринькою, рейдом на кланового боса й клановими війнами
4. **Карта світу:** кожна категорія (🍽️ Food, 🐾 Animals…) стає островом, який відкривається, коли вивчаєш його слова
5. **Сезони:** приблизно кожні 6 тижнів нова тема (Хелловін, Зима…) з безкоштовним шляхом нагород і ексклюзивними предметами
6. **Події:** наприклад, «Тиждень фразових дієслів: x2 монети»
7. **Колоди спільноти:** ділишся набором слів, а інші копіюють його собі чи у свій Notion. Лайки, топ колод
8. **Слово дня** з твоєї ж таблиці
9. **Нагадування:** безкоштовні push-сповіщення на кшталт «Вогник згасне через 2 години 🔥»
10. **Турніри:** щотижнева сітка дуелей на вибування

## 11. Функції десктопної програми

- **Слово на робочому столі:** кожні N хвилин поверх усіх вікон з'являється невелике віконце з карткою, на яку можна відповісти, не відриваючись від роботи
- **Гаряча клавіша:** виділяєш англійське слово будь-де, тиснеш Ctrl+Shift+E, і воно додається в Notion
- Іконка в треї, тихий режим, запуск разом із системою
- Автооновлення

## 12. Модерація

### Ролі

Власник (ти) → адміни → модератори → користувачі

### Дії

Попередження, мут (на час або назавжди), бан (на час або назавжди), видалення повідомлення, повільний режим у кімнаті, закриття кімнати

### Автоматика

- Фільтр лайки кількома мовами (бібліотека плюс власні списки слів)
- Антиспам: ліміт на частоту повідомлень, повтори й посилання
- Нові акаунти перші 24 години не можуть надсилати посилання й писати незнайомим в особисті
- Мут і бан перевіряє сервер, а не інтерфейс

### Скарги

Кнопка «Поскаржитися» → черга в панелі модератора → рішення

### Панель адміна

Користувачі, ролі, скарги, журнал усіх дій модераторів, статистика, керування магазином і подіями, видача предметів

### Правила

Сторінка правил спільноти, згода з правилами під час першого входу в чат, мінімальний вік для чату 13+

## 13. Мови інтерфейсу

- На старті українська та англійська
- Архітектура під будь-яку мову: переклади лежать в окремих файлах, і нові мови можуть додавати учасники на GitHub
- Мова перекладу слів береться з таблиці користувача, і озвучка під неї підлаштовується

## 14. Безпека

- Row Level Security на кожній таблиці: користувач бачить і змінює лише своє
- Нагороди, покупки, дуелі, мут і бан проходять тільки через серверні функції
- Секрети (ключі Notion OAuth, сервісний ключ Supabase, дані тестового акаунта) зберігаються лише в змінних оточення
- Політика конфіденційності та умови використання (Notion вимагає їх для публічних інтеграцій)

### Публікація на GitHub

Репозиторій публічний. Перед першою публікацією і перед кожною наступною проходимо перевірку безпеки:

- у коді та історії git немає секретів (сканування gitleaks), `.env` додано в `.gitignore`
- RLS увімкнено на всіх таблицях, і жодна серверна функція не довіряє даним з браузера
- залежності без відомих вразливостей (`npm audit`), Dependabot увімкнено
- код переглянуто на типові вразливості: XSS у чаті, підробку нагород, обхід мута чи бана, витік токенів Notion

## 15. Структура репозиторію

```

src/locales/    переклади інтерфейсу
docs/           документація
```
